# Capturas para revisión de línea gráfica

Este directorio contiene capturas reales de la interfaz generadas con Playwright.

Última actualización: 11 de septiembre de 2026. Incluye la revisión de legibilidad, las portadas por temática, el CTA principal y la biblioteca agrupada por Capa, Capote y Tripa.

- `desktop/`: vistas de escritorio a 1440 px.
- `mobile/`: vistas móviles a 390 px.
- `experiences/`: estados especiales de la biblioteca, la experiencia inmersiva y el configurador.

Las imágenes pueden compartirse con una herramienta de análisis visual para evaluar consistencia, jerarquía, legibilidad y dirección de arte.

## Contexto sugerido para la revisión

> Evalúa esta interfaz como una presentación editorial e inmersiva sobre tabaco y cigarros. No es una tienda y no muestra precios. Analiza coherencia visual, jerarquía, tipografía, paleta, navegación, ritmo, legibilidad, tratamiento fotográfico y continuidad entre la biblioteca de hojas y el configurador de cigarros.
